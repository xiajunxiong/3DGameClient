Unity6.4 客户端热更多语言 Demo
基于 Unity 6.4 的游戏客户端示例项目，集成资源热更、代码热更、多语言本地化等常用模块，配套自研游戏服务端，可完整支持版本更新、多语言适配、基础网络交互等业务流程。
技术栈
引擎：Unity 6.4
资源热更：Addressables (AA)
代码热更：HybridCLR
本地化：Unity Localization
项目特点
支持资源 + 代码双热更，可线上增量更新
内置完整多语言管理，支持运行时切换语种
已对接配套服务端，包含基础网络通信逻辑
